## 🚀 РАЗВЕРТЫВАНИЕ

### Docker Compose

```bash
# Клонирование репозитория
git clone <repository-url>
cd psychology-bot

# Настройка переменных окружения
cp .env.example .env
# Отредактировать .env файл

# Запуск всех сервисов
docker-compose up -d

# Применение миграций
docker-compose exec backend npm run db:migrate

# Заполнение начальными данными
docker-compose exec backend npm run db:seed
```

### Ручная установка

```bash
# Backend
cd backend
npm install
npm run db:generate
npm run db:migrate
npm run db:seed
npm run build
npm start

# Bot
cd ../bot
npm install
npm run build
npm start

# Frontend
cd ../frontend
npm install
npm run build
npm start
```
