# Task Repository

Этот Git репозиторий содержит различные задачи и проекты, организованные по категориям.

## Структура репозитория

```
task/
├── task1-testing/          # Тестирование и эксперименты
├── task2-documentation/    # Документация проектов
└── task3-unknown-language/ # Проекты на различных языках
```

## Описание папок

### 📁 task1-testing

Папка для тестирования различных решений, экспериментов и прототипов.

### 📁 task2-documentation

Техническая документация, руководства пользователя и архитектурные решения.

### 📁 task3-unknown-language

Проекты на различных языках программирования и экспериментальные решения.

**Текущие проекты:**

-   **noteapp** - RESTful API для управления заметками на Go

## Как использовать

1. Клонируйте репозиторий:

    ```bash
    git clone <repository-url>
    cd task
    ```

2. Перейдите в нужную папку для работы с конкретной задачей

3. Следуйте инструкциям в README файлах каждой папки

## Контрибьюция

При добавлении новых проектов:

1. Выберите подходящую папку или создайте новую
2. Добавьте README с описанием проекта
3. Следуйте принятым соглашениям по именованию
