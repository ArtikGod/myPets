# 🚀 Pet Projects Portfolio

> Коллекция моих пет-проектов, демонстрирующих различные технологии и подходы к разработке. Каждый проект представляет собой полнофункциональное приложение с собственной документацией и инструкциями по запуску.

---

## 🛠 Технологический стек

### 🔧 Backend

-   **Node.js** - основная платформа
-   **TypeScript** - типизированная разработка
-   **NestJS** - enterprise фреймворк
-   **Express** - веб-сервер

### 🗄️ Базы данных

-   **MongoDB** - документо-ориентированная БД
-   **PostgreSQL** - реляционная БД
-   **SQLite** - встроенная БД для прототипов

### 🎨 Frontend

-   **React** - пользовательские интерфейсы
-   **TypeScript** - типизированный фронтенд
-   **Vite** - современная сборка
-   **Vue** - прогрессивный фреймворк

### ⚙️ DevOps & Tools

-   **Docker** - контейнеризация
-   **Docker Compose** - оркестрация сервисов
-   **Jest** - тестирование
-   **Swagger** - API документация
-   **Nginx** - веб-сервер и прокси

### 🔌 Интеграции

-   **Telegram Bot API** - боты и уведомления
-   **Google Sheets API** - экспорт данных
-   **amoCRM API** - CRM интеграция
-   **Speech Recognition** - голосовые интерфейсы

---

## 🚀 Быстрый старт

Каждый проект содержит собственный README с детальными инструкциями по установке и запуску.

```bash
# Общий подход для большинства проектов
git clone <repository-url>
cd <project-name>
npm install
npm start
```
