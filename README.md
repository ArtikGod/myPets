# API для бронирования мест на мероприятия

## Описание

API для бронирования мест на мероприятия с использованием Node.js и PostgreSQL.

## Установка и запуск

1. Установить зависимости:

```bash
npm install
```

2. Настроить PostgreSQL и создать базу данных `booking_db`

3. Выполнить SQL скрипт для создания таблиц:

```bash
psql -U postgres -d booking_db -f db_init.sql
```

4. Настроить переменные окружения в файле `.env`

5. Запустить сервер:

```bash
npm start
```

## Тестирование

Запуск тестов:

```bash
npm test
```

Тесты включают:

-   Модульные тесты сервиса бронирований с мок базой данных
-   Интеграционные тесты API роутов
-   Проверку всех сценариев ошибок
-   Покрытие кода

## API Endpoints

### POST /api/bookings/reserve

Бронирование места на мероприятие

**Тело запроса:**

```json
{
    "event_id": 1,
    "user_id": "user123"
}
```

**Успешный ответ (201):**

```json
{
    "status": "success",
    "data": {
        "id": 1,
        "event_id": 1,
        "user_id": "user123"
    }
}
```

**Ошибки:**

-   400: Некорректные данные или нет доступных мест
-   409: Пользователь уже забронировал место на это мероприятие
-   500: Внутренняя ошибка сервера

## Структура базы данных

### Таблица events

-   id (SERIAL PRIMARY KEY)
-   name (VARCHAR)
-   total_seats (INT)

### Таблица bookings

-   id (SERIAL PRIMARY KEY)
-   event_id (INT, ссылка на events)
-   user_id (VARCHAR)
-   created_at (TIMESTAMP)

### Индексы для оптимизации производительности

-   `idx_bookings_event_id` - индекс по event_id для быстрого поиска бронирований по событию
-   `idx_bookings_user_id` - индекс по user_id для быстрого поиска бронирований пользователя
-   `idx_bookings_event_user` - составной индекс для проверки дублирования бронирований
-   `idx_bookings_created_at` - индекс по времени создания для сортировки и фильтрации
