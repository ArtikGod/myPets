# Голосование за идеи LogicLike

Простое веб-приложение, где пользователи могут голосовать за идеи развития продукта LogicLike. Каждый IP-адрес может проголосовать максимум 10 раз и только один раз за каждую идею.

## Что умеет приложение

-   📋 Показывает список идей, отсортированный по популярности
-   👍 Позволяет голосовать за понравившиеся идеи
-   🚫 Не дает голосовать дважды за одну идею
-   🔢 Ограничивает количество голосов с одного IP (максимум 10)
-   📱 Работает на телефонах и компьютерах

## Как запустить

Нужен только Docker. Больше ничего устанавливать не надо!

1. **Скачайте проект:**

```bash
git clone <ссылка-на-репозиторий>
cd logiclike-voting
```

2. **Запустите одной командой:**

```bash
docker-compose up
```

3. **Откройте в браузере:**

-   Приложение: http://localhost:3000
-   API: http://localhost:3001

Готово! 🎉

## Для разработчиков

### Что внутри

-   **Frontend**: React приложение на TypeScript
-   **Backend**: Node.js сервер с Express
-   **База данных**: PostgreSQL
-   **Веб-сервер**: Nginx

### Как работает

1. Пользователь заходит на сайт и видит список идей
2. Нажимает кнопку "Голосовать" рядом с понравившейся идеей
3. Система проверяет:
    - Не голосовал ли уже за эту идею
    - Не превысил ли лимит в 10 голосов
4. Если все ОК - засчитывает голос и обновляет счетчик

### Разработка без Docker

Если хотите запускать части проекта отдельно:

**Backend:**

```bash
cd backend
npm install
npm run dev
```

**Frontend:**

```bash
cd frontend
npm install
npm start
```

**База данных:**

```bash
docker run -d --name postgres \
  -e POSTGRES_DB=logiclike_voting \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres \
  -p 5432:5432 \
  postgres:15-alpine
```

### API

**Получить все идеи:**

```
GET /api/ideas
```

**Проголосовать за идею:**

```
POST /api/ideas/:id/vote
```

### Полезные команды

```bash
# Остановить все сервисы
docker-compose down

# Посмотреть логи
docker-compose logs -f

# Пересобрать образы
docker-compose build

# Подключиться к базе данных
docker-compose exec database psql -U postgres -d logiclike_voting
```
