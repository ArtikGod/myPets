# amoCRM API Integration

Backend-приложение для интеграции с amoCRM через REST API. Приложение предоставляет HTTP-эндпоинты для управления сделками и контактами в amoCRM.

## Технологии

- Node.js
- Express.js
- JavaScript
- Архитектура MVC

## Установка и запуск

1. Клонировать репозиторий
2. Установить зависимости: `npm install`
3. Создать файл `.env` на основе `.env.example` и заполнить его своими данными
4. Запустить приложение: `npm start`

## API Endpoints

### Сделки (Leads)

- `POST /leads` - создание новой сделки в amoCRM
- `PUT /leads/{id}` - изменение существующей сделки
- `GET /leads/{id}` - получение информации о сделке

### Контакты (Contacts)

- `POST /contacts` - создание нового контакта в amoCRM
- `PUT /contacts/{id}` - изменение данных контакта
- `GET /contacts/{id}` - получение информации о контакте

### Связи (Links)

- `POST /link` - привязка контакта к сделке
- `POST /unlink` - удаление связи между контактом и сделкой

## Архитектура

Приложение построено по архитектуре MVC:

- **Controllers** - обработка HTTP-запросов и формирование ответов
- **Services** - бизнес-логика приложения
- **Models** - модели данных

Зависимости передаются через конструктор, что обеспечивает гибкость и тестируемость кода.
