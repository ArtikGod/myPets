## Проекты

### noteapp

RESTful API для управления заметками, написанное на Go с использованием SQLite.

**Технологии:**

-   Go 1.21
-   SQLite
-   Chi Router
-   Модульная архитектура

**API Endpoints:**

-   `GET /notes` - получение всех заметок
-   `POST /notes` - создание заметки
-   `PUT /notes/{id}` - обновление заметки
-   `DELETE /notes/{id}` - удаление заметки

Подробная документация находится в `noteapp/README.md`.
