# RESTful Notes API

RESTful веб-приложение на Python для управления заметками с использованием SQLite базы данных.

## Архитектура

Приложение построено с использованием модульной архитектуры:

-   **main.py** - точка входа, инициализация сервера, БД и маршрутизатора
-   **model/** - модели данных (Note)
-   **db/** - настройка подключения к SQLite и операции с БД
-   **repository/** - слой доступа к данным, CRUD операции
-   **service/** - бизнес-логика и валидация
-   **handler/** - HTTP обработчики для REST API эндпоинтов

## Требования

-   Python 3.8+
-   Flask 2.3.3
-   SQLite (встроен в Python)

## Установка и запуск

1. Клонируйте репозиторий или скопируйте файлы проекта
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Запустите приложение:

```bash
python main.py
```

Сервер запустится на `http://localhost:5000`

## API Эндпоинты

### GET /api/notes

Получить все заметки

**Ответ:**

```json
{
    "notes": [
        {
            "id": 1,
            "text": "Моя первая заметка",
            "created_at": "2024-01-01T12:00:00"
        }
    ],
    "count": 1,
    "message": "Заметки получены успешно"
}
```

### GET /api/notes/{id}

Получить заметку по ID

**Ответ:**

```json
{
    "note": {
        "id": 1,
        "text": "Моя первая заметка",
        "created_at": "2024-01-01T12:00:00"
    },
    "message": "Заметка получена успешно"
}
```

### POST /api/notes

Создать новую заметку

**Запрос:**

```json
{
    "text": "Новая заметка"
}
```

**Ответ:**

```json
{
    "note": {
        "id": 2,
        "text": "Новая заметка",
        "created_at": "2024-01-01T12:05:00"
    },
    "message": "Заметка создана успешно"
}
```

### PUT /api/notes/{id}

Обновить заметку

**Запрос:**

```json
{
    "text": "Обновленная заметка"
}
```

**Ответ:**

```json
{
    "note": {
        "id": 1,
        "text": "Обновленная заметка",
        "created_at": "2024-01-01T12:00:00"
    },
    "message": "Заметка обновлена успешно"
}
```

### DELETE /api/notes/{id}

Удалить заметку

**Ответ:**

```json
{
    "message": "Заметка с ID 1 удалена успешно"
}
```

### GET /api/notes/count

Получить количество заметок

**Ответ:**

```json
{
    "count": 5,
    "message": "Количество заметок получено успешно"
}
```

## Валидация

-   Поле `text` обязательно
-   Текст не может быть пустым
-   Длина текста: от 1 до 500 символов

## Обработка ошибок

Все ошибки возвращаются в формате JSON:

```json
{
    "error": "Описание ошибки",
    "message": "Пользовательское сообщение"
}
```

**HTTP коды ответов:**

-   200 - Успешная операция
-   201 - Ресурс создан
-   400 - Ошибка валидации или неверный запрос
-   404 - Ресурс не найден
-   405 - Метод не разрешен
-   500 - Внутренняя ошибка сервера

## Структура базы данных

**Таблица notes:**

-   `id` - INTEGER PRIMARY KEY AUTOINCREMENT
-   `text` - TEXT NOT NULL
-   `created_at` - DATETIME DEFAULT CURRENT_TIMESTAMP

## Тестирование API

Примеры запросов с помощью curl:

```bash
# Получить все заметки
curl -X GET http://localhost:5000/api/notes

# Создать заметку
curl -X POST http://localhost:5000/api/notes \
  -H "Content-Type: application/json" \
  -d '{"text": "Тестовая заметка"}'

# Получить заметку по ID
curl -X GET http://localhost:5000/api/notes/1

# Обновить заметку
curl -X PUT http://localhost:5000/api/notes/1 \
  -H "Content-Type: application/json" \
  -d '{"text": "Обновленная заметка"}'

# Удалить заметку
curl -X DELETE http://localhost:5000/api/notes/1

# Получить количество заметок
curl -X GET http://localhost:5000/api/notes/count
```

## Особенности реализации

-   Использование SQLite для простоты развертывания
-   Модульная архитектура для легкости тестирования и поддержки
-   Полная валидация входных данных
-   Обработка всех типов ошибок
-   Логирование операций с базой данных
-   Автоматическое создание таблиц при первом запуске
